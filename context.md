We are building a frontend prototype for a university project in partnership with Medibank.

Product name: Medibank Student Companion

The goal is to extend the existing Medibank mobile app experience for international students with new features that support them from pre-arrival to post-study transition.

For now, focus only on frontend, UI, workflows, and clickable prototype interactions. Do not set up Supabase or backend yet. Use mock data and local state.

The prototype should first recreate the existing Medibank app design style, then we will add new student-focused features on top of it.

Core product concept:
Medibank has a unique advantage because OSHC students purchase their insurance before arriving in Australia. This makes Medibank one of the earliest touchpoints in the international student journey. The Student Companion uses this opportunity to support students from day one by helping them prepare, settle into Australia, understand healthcare, build community, and transition smoothly from OSHC to OVHC.

Main modules we will build later:
1. Home dashboard
2. Guided student journey
3. Pre-arrival checklist
4. First 30 days in Australia
5. MediGuide AI assistant
6. Community and events
7. Health points and rewards
8. OSHC to OVHC transition flow
9. Profile and notifications

Technical requirements:
- Build using React
- Mobile-first layout, optimized for iPhone screen size
- Use reusable components
- Use mock data only
- Use local state for interactions
- No backend integration yet
- Structure the app so Supabase can be added later
- Create clean folders such as components, pages, data, hooks, styles if appropriate

Design requirements:
- Recreate the existing Medibank mobile app visual style based on the screenshot I provide
- Use a red Medibank-style background
- White rounded cards
- Dark navy/black text
- Blue primary CTA buttons
- Simple outline icons
- Large friendly typography
- Bottom navigation bar
- Clean healthcare app feel
- Do not create a generic startup app look
- The prototype should feel like a realistic extension of the Medibank app

Initial objective:
Set up the app architecture, routing/navigation structure, reusable design system, and base mobile app shell. Then create the first screen by recreating the attached Medibank home screen as closely as possible.
